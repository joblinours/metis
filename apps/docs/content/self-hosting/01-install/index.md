Most operators install Metis Suite with the bootstrap script. It sets up Docker, writes the settings file, and starts every service for you. Read the pages in order the first time.

- [Requirements](/self-hosting/install/requirements): what the server needs before you start.
- [Install with the bootstrap script](/self-hosting/install/install-with-bootstrap): deploy the whole stack with one command.
- [Install with Docker Compose](/self-hosting/install/install-with-docker-compose): run the stack yourself, without the script.
- [First run](/self-hosting/install/first-run): use the setup code to create the first account and become the owner.
- [Domain and HTTPS](/self-hosting/install/domain-and-https): serve the instance on your own domain with a certificate.
