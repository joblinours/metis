Three tools help you find a message: the search box, the tabs above the list, and your provider's folders in the sidebar. The search box and the tabs work together, so a search only shows results from the tab you are on.

## Search

<Steps>
  <Step title="Click the search box">
    The box above the list says **Search messages…**. You can also press **m** then **/** to jump to
    it.
  </Step>
  <Step title="Type what you are looking for and press Enter">
    The search runs when you press Enter. It covers the mailbox you are in, or every mailbox when
    you are in **All inboxes**.
  </Step>
  <Step title="Clear the search">
    Click the **X** in the box to clear it and go back to the folder.
  </Step>
</Steps>

:::tip
The tab you are on still filters your results. If you cannot find a message, switch to the **All** tab.
:::

A few things to know about search:

- Search returns one set of results. Scrolling does not load more.
- For mailboxes connected over IMAP, search matches plain text in your Inbox, Archive and Sent folders. Results are not ranked.
- While a search is active, the list does not check for new mail.

## Search with filters

To search with filters, such as the sender, a date or an attachment, use workspace search. Click **Search** on the left rail, or press **Ctrl** + **K** (**⌘** + **K** on a Mac). If you open it from a mailbox, it starts with a filter for that mailbox.

For example:

| You type                    | Finds                                 |
| --------------------------- | ------------------------------------- |
| `from:sam invoice`          | Mail from Sam that mentions "invoice" |
| `is:unread has:attachment`  | Unread mail with an attachment        |
| `mail-folder:sent after:7d` | Mail you sent in the last 7 days      |

From a result, you can reply, archive, star or snooze a message without opening it. See [Search your workspace](/guide/search/search-your-workspace) and, for every filter, [Search syntax](/guide/reference/search-syntax).

## Tabs

The tabs above the list narrow what the folder shows. In order, they are:

| Tab         | Shows                                              |
| ----------- | -------------------------------------------------- |
| **All**     | Every message in the folder                        |
| **Unread**  | Every message in the folder that you have not read |
| **Starred** | Every message in the folder that you starred       |

The number at the right of the tab row counts the conversations (rows) the list shows, out of the mail loaded so far. It is not the total for the folder. In the Inbox, it leaves out muted conversations, because the Inbox hides them.

- Every folder opens on **All**.
- Metis Suite remembers your tab for each mailbox and folder while you work, so opening and closing messages keeps you on the same tab.
- On the **Unread** tab, a message you open stays in the list even though it is now read, so it does not jump away while you read it.

**Unread** and **Starred** ask your mail provider for every unread or starred message in the folder, not only the ones already loaded:

- More load as you scroll.
- In the **Starred** folder of a mailbox connected over IMAP, they look in your Inbox, Archive and Sent together and show at most the 50 newest matches. Scrolling does not load more there, and no **Load more** button shows. So the **Unread** tab in that folder can show only a few messages, or none.
- In the **Starred** folder of an Outlook mailbox, they look only in your Inbox. So they can show fewer messages than the **All** tab there.
- The automatic check for new mail does not update them. They refresh when you switch to them from another tab, folder, mailbox or **Read later**, and when you reload the page.
- Opening or closing a message does not refresh them. Clicking the tab you are already on does not either.

Sometimes **Unread** or **Starred** shows **No emails** and "Nothing in this filter", but the folder has more mail to check. A **Load more** button then shows under the note:

- Each click checks the next batch of messages. The button cannot be clicked again while it works.
- With nothing loaded yet, the note and the button make way for grey loading placeholders while it checks.
- When the list has loaded messages but the tab hides them all, the button shows a spinning icon while it checks. This happens, for example, on **Unread** after you read everything loaded, or on **Starred** after you unstar everything loaded.
- If the next batch has no matches either, the note and the button show again. The button goes away when there is nothing left to check.
- If a match turns up, it shows in the list. The list then keeps loading on its own ("Loading more…") until it fills the screen, and loads more as you scroll. The end of the list says "end of list".
- Until a match turns up, the list never loads more on its own.

A batch can come back with no matches only on **Outlook**, **Zoho Mail**, **Cloudflare Email** and **Resend** mailboxes, so you see this mainly there. Gmail and IMAP batches on these tabs always hold matches.

## Open a provider folder

For Gmail, Outlook and Zoho Mail mailboxes, the **Folders** section of the sidebar lists your account's own folders and labels. Clicking a folder lists its emails. A folder list has no tabs and does not check for new mail on its own. See [Folders and provider labels](/guide/mail/folders-and-provider-labels#open-a-folder).

## Read later

**Read later** in the sidebar opens its own page. It lists every message you saved in this mailbox, from any folder. A search on that page shows only the results you saved. See [Snooze and read later](/guide/mail/snooze-and-read-later).
